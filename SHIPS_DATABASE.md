## 🚀 Como Popular no Banco de Dados

```bash
# Executar script completo
pnpm run setup:all-ships

# Ou manualmente
tsx scripts/seed-all-ships-complete.mjs
```

### O que o script faz:

1. ✅ Verifica se a companhia existe
2. ✅ Verifica se o navio já existe (por slug)
3. ✅ Se existe: **atualiza** os dados
4. ✅ Se não existe: **cria** novo registro
5. ✅ Adiciona foto oficial (imageUrl)
6. ✅ Adiciona todas as especificações

### Tempo estimado:
- **2-3 minutos** para 127 navios
- Processamento em batch
- Retry automático em caso de erro
